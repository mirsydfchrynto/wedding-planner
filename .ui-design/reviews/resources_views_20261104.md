## Minor Issues (Remediated)

### Issue 1: Missing `scope="col"` on Data Table Headers

**Severity:** Minor (Remediated)
**Location:** `resources/views/livewire/admin-vendor-manager.blade.php:27-32`, `resources/views/budget/index.blade.php:133-140`
**Category:** Usability / Accessibility (WCAG 1.3.1)

**Problem:**
Table header cells (`<th>`) in the Livewire Admin Vendor SLA table and the Budget Ledger table lacked explicit `scope="col"` attributes.

**Impact:**
Screen readers rely on `scope="col"` to announce column headers accurately when navigating across financial ledger cells.

**Recommendation:**
Add `scope="col"` to all `<th>` elements. (Applied).

**Code Example:**

```html
<!-- Before -->
<th class="py-2.5 pr-3 font-semibold">Mitra Vendor</th>

<!-- After -->
<th scope="col" class="py-2.5 pr-3 font-semibold">Mitra Vendor</th>
```

### Issue 2: Global `:focus-visible` Outline Ring Consistency

**Severity:** Minor (Remediated)
**Location:** `resources/css/app.css:58`
**Category:** Usability / Keyboard Navigation (WCAG 2.4.7)

**Problem:**
While `.editorial-input:focus` defined a border color transition, interactive links (`<a>`) and buttons (`<button>`) relied on browser default focus rings which vary across platforms.

**Impact:**
Keyboard-only users benefit from a high-contrast, consistent 2px focus ring (`--color-champagne`) with a 2px offset across all interactive elements.

**Recommendation:**
Define a global `:focus-visible` rule in `@layer base` in `resources/css/app.css`. (Applied).
